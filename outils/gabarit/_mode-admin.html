/* Le mode administration (§ 10) : fiche et masquage d'une zone, libellés placés à la main. Suite de `_admin1.html`, dans le même script. */ /* ============================================================ 10. Mode administration — le branchement Il n'existe que dans la page dédiée, et seulement une fois l'utilisateur authentifié. Son état, `ADMIN`, et le retrait de ses commandes de la page publique vivent dans `modules/mode-admin.mjs`, que le code soudé lit par accesseur, comme avant par son nom ; le profil du compte, `PROFIL_ADMIN`, dans `modules/acces-admin.mjs`, qui le lit, et que la fenêtre des réglages importe (`modules/reglages.mjs`). Le reste est d'exploitant, dans des modules que seul `plan-admin.mjs` embarque : l'ouverture du mode et la bande de l'outil (`modules/bande-admin.mjs`), la fiche d'une zone, son masquage et l'écriture des colonnes de l'événement (`modules/fiche-zone.mjs`), l'outil qui place un libellé à la main (`modules/placement-libelles.mjs`). Ce que le visiteur reçoit de ce dernier — le placement relu au dessin des noms — est dans `modules/libelle-place.mjs`. Ceux qui ont encore à recevoir se branchent ici, à la place que leur code tenait : ce qu'ils ne peuvent importer sans boucler — la reprise d'un emplacement, l'outil de dessin, qui les importent — leur est confié. La bande de l'outil et le placement relu au dessin des noms importent tout : ils n'ont plus de branchement. ============================================================ */ /* @admin — la fiche d'une zone, qu'on ne remplit qu'en administration */ brancheFicheZone({ majPaletteGeo }); /* @fin-admin */ /* @admin — le placement des libellés à la main */ branchePlacementLibelles({ activeCalque, modeGeometrie }); /* @fin-admin */
