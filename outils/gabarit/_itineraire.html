Itinéraire — d'un point du salon à un autre ============================================================ */ /** * Un visiteur cherche le G77 ; il est devant le E10 et n'a aucune idée du * chemin. Son téléphone ne l'aidera pas : sous une charpente métallique le * GPS ne situe rien, et poser des balises dans les allées demanderait un * budget et une pose que personne n'a. On ne lui demande donc pas où il est — * il désigne son départ comme il désigne son arrivée, dans la même liste que * la recherche. * * Reste à trouver le chemin. Les données ne décrivent aucune allée : elles ne * donnent que des emplacements. L'allée, c'est ce qui reste — le vide entre * les stands. On la calcule donc en creux : le hall est pavé de cases d'un * demi-mètre, on noircit ce que les stands occupent, et on cherche la suite * de cases blanches la plus courte entre deux points. * * Ce détour par la grille a un mérite qui vaut à lui seul le calcul : le mode * PMR y devient presque gratuit. Un escalier, une pente, un passage trop * étroit se noircissent comme un stand, et la même recherche rend un autre * chemin — ou dit franchement qu'il n'y en a pas. */ /* Un demi-mètre par case : plus fin, la grille d'un pavillon dépasse le million de cases pour un tracé qui ne change plus ; plus grossier, une allée de deux mètres se referme. */ const PAS_GRILLE = .5; /* Ce qu'on écarte des stands. Le chemin est calculé pour un point sans épaisseur : on épaissit donc les obstacles de la moitié du passage nécessaire. Quatre-vingt-dix centimètres pour un marcheur ; un mètre quarante en mode accessible, la largeur qu'exige un fauteuil roulant pour circuler et se croiser. Un couloir plus étroit disparaît de la grille, et le trajet passe ailleurs — c'est l'essentiel de ce que « PMR » change. */ const DEGAGEMENT = .45; const DEGAGEMENT_PMR = .70; /* Allure de salon, arrêts non compris : on marche moins vite entre deux allées pleines que sur un trottoir. */ const ALLURE = 1.1; // m/s const ALLURE_PMR = .8; /** * Ce que coûte un virage, en cases. * * Entre deux points d'une allée, une grille offre des milliers de chemins de * même longueur : tout escalier de marches horizontales et verticales vaut la * diagonale qu'il approche. Sans prix du virage, A* en choisit un au hasard, * et le trajet traverse l'allée en biais au lieu de la suivre. À quatre cases * — deux mètres — un crochet ne se justifie plus que s'il fait gagner * davantage, et les tronçons redeviennent de longues lignes droites. */ const TOURNANT = 4; /** * De quoi préférer le milieu de l'allée à ses bords. * * La pénalité s'éteint à deux mètres du mur le plus proche : au-delà — dans * une aire dégagée, une entrée, un carrefour — aucun « milieu » n'a de sens, * et vouloir le tenir ferait faire des détours pour rien. */ const PORTEE_CENTRE = 4; // cases const POIDS_CENTRE = .5; // au ras du mur, une case coûte une demie de plus /* ------------------------------------------------------------ L'enveloppe du hall ------------------------------------------------------------ */ /** * L'emprise d'un pavillon est une boîte : elle déborde d'une douzaine de * mètres autour des stands, et rien n'y empêcherait un trajet de contourner * le hall par l'extérieur — derrière les stands de périphérie, là où il n'y a * que le mur. On borne donc la marche à l'enveloppe convexe des emplacements * eux-mêmes : les stands du pourtour en dessinent le bord, et on ne passe * plus derrière eux. * * Le fond de plan porterait les vrais murs, mais mêlés aux cotes, aux * hachures et au mobilier : les lire découperait le hall en morceaux au lieu * de le fermer. */ function sommets(o){ const n = String(o.d).match(/-?\d*\.?\d+/g) || []; const l = []; for (let i = 0; i + 1 < n.length; i += 2) l.push([+n[i], +n[i + 1]]); return l; } /** Enveloppe convexe, parcours monotone d'Andrew. */ const ENVELOPPES = new Map(); function enveloppe(p){ const garde = ENVELOPPES.get(p.id); if (garde) return garde; const pts = []; for (const o of p.stands) pts.push(...sommets(o)); for (const o of p.zones) pts.push(...sommets(o)); pts.sort((a, b) => a[0] - b[0] || a[1] - b[1]); const cote = (suite) => { const r = []; for (const q of suite){ while (r.length > 1){ const a = r[r.length - 2], b = r[r.length - 1]; if ((b[0] - a[0]) * (q[1] - a[1]) - (b[1] - a[1]) * (q[0] - a[0]) > 0) break; r.pop(); } r.push(q); } r.pop(); return r; }; let bord = pts.length < 3 ? [] : cote(pts).concat(cote(pts.slice().reverse())); /* Un pavillon sans emplacement — cela existe, le temps d'une première synchronisation — n'a pas d'enveloppe : on retombe sur son emprise, à défaut de mieux. */ if (bord.length < 3){ const e = p.emprise; bord = [[e.x0, e.y0], [e.x1, e.y0], [e.x1, e.y1], [e.x0, e.y1]]; } const t = new Path2D(); bord.forEach((q, i) => i ? t.lineTo(q[0], q[1]) : t.moveTo(q[0], q[1])); t.closePath(); ENVELOPPES.set(p.id, t); return t; } /* ------------------------------------------------------------ La grille de marche ------------------------------------------------------------ */ /* Une grille par pavillon et par mode : elle ne dépend que des emplacements et des obstacles dessinés, qui ne bougent qu'en administration. */ const GRILLES = new Map(); function oublieGrilles(){ GRILLES.clear(); } /** Les calques de dessin d'un pavillon quelconque, pas seulement l'affiché. */ const calquesDe = (p) => (typeof DESSINS === "object" && DESSINS[p.id]) || []; /** Les repères posés sur les calques montrés d'un pavillon. * Un calque masqué ne compte pas : le trajet doit s'expliquer par ce qu'on * voit, et contourner un obstacle invisible passerait pour un bogue. */ function reperesDe(p){ const l = []; for (const c of calquesDe(p)){ if (c.visible === false) continue; for (const f of c.formes || []) if (f.t === "repere" && f.txt) l.push(f); } return l; } /* ------------------------------------------------------------ Ce que l'exploitant déclare : où l'on marche, ce qui barre ------------------------------------------------------------ */ /** * Un bloc sanitaire, un local technique, une estrade : rien de cela n'est un * stand, et rien n'en ressort des données. Cela vit dans le fond de plan, que * le calcul ignore — d'où des trajets qui traversaient les WC. * * On a d'abord voulu lire ce fond. Il est bien rangé en sous-calques nommés — * « 5-SANITAIRES », « INFOPRO_SURFACE_POTEAUX » — mais ces noms sont ceux du * bureau d'études qui a produit le DWG, et ils changent d'un salon à l'autre : * ce qui marche pour trois pavillons ne s'industrialise pas. Le dessin est un * export de traits, où murs, cotes et hachures se ressemblent ; deviner y * revient à parier. * * On demande donc, plutôt que de deviner. Un calque de dessin reçoit un rôle, * et tout ce qu'on y trace le porte : * * obstacle ce qui est dessiné barre le passage à tout le monde * pmr il ne le barre qu'en itinéraire accessible * circulation ce qui est dessiné dit où l'on peut marcher ; tout le reste * du pavillon devient infranchissable * * Les deux bouts par lesquels on peut prendre le problème, donc. Barrer est * presque toujours le plus court — un bloc sanitaire fait un rectangle, une * allée en fait cinquante — et c'est ce que la liste propose en premier. La * circulation reste là pour le hall dont le vide n'est, dans l'ensemble, pas * praticable ; elle coûte alors une après-midi de tracé, et il faut le savoir * avant de s'y mettre. * * Le rôle vit dans CONF, comme l'ordre de la pile : les colonnes de * `calque_dessin` sont fixées, celles des réglages ne le sont pas — et les * réglages partent aux visiteurs à la publication, ce qui est exactement ce * qu'on veut. */ const ROLES_ITI = [ { v: "", nom: "Aucun" }, { v: "obstacle", nom: "Infranchissable" }, { v: "pmr", nom: "Infranchissable en fauteuil" }, { v: "circulation", nom: "Où l'on peut marcher" }, ]; const cleRoleIti = (id) => "_iti:" + id; const roleIti = (c) => (CONF[cleRoleIti(c.id)] || {}).role || ""; const nomRoleIti = (r) => (ROLES_ITI.find(x => x.v === r) || ROLES_ITI[0]).nom; /** * Les formes d'un pavillon portant un rôle donné. * * Un calque masqué ne compte pas : le trajet doit s'expliquer par ce qu'on * voit à l'écran, et contourner un obstacle invisible passerait pour un bogue. * Une ligne n'a pas de surface — elle barre par son trait, et ne saurait * délimiter une circulation. */ function formesRole(p, role){ const l = []; for (const c of calquesDe(p)){ if (c.visible === false || roleIti(c) !== role) continue; for (const f of c.formes || []){ if (f.t === "rect" || f.t === "poly") l.push({ d: cheminForme(f), trait: false }); else if (f.t === "ligne" && role !== "circulation") l.push({ d: cheminForme(f), trait: true }); } } return l; } /** * Ce qui barre la route à un fauteuil, et à lui seul./** * Ce qui barre la route à un fauteuil, et à lui seul. * * Deux sources, parce qu'un salon en a deux. Les escaliers et les escalators * sont déjà signalés par un repère, et leur pastille est posée dessus : on * reprend son emprise telle qu'elle est dessinée — ce qu'on voit est ce qui * est évité. Les pentes, les emmarchements, les estrades n'ont pas de * pictogramme et n'en auront pas : l'exploitant les entoure d'un rectangle ou * d'un polygone, et coche « obstacle pour les PMR » sur la forme. */ function obstaclesPmr(p){ const l = formesRole(p, "pmr"); /* Les escaliers et les escalators sont déjà signalés par un repère, posé sur eux : leur pastille dit où ils sont, on la reprend telle quelle. Ce qu'on voit est ce qui est évité, sans rien redessiner. */ for (const c of calquesDe(p)){ if (c.visible === false) continue; for (const f of c.formes || []){ if (f.t !== "repere") continue; const pic = f.picto || pictoDe(f.txt); if (pic !== "escalier" && pic !== "escalator") continue; const cote = (f.taille || 2) * 2.4; const x = f.pts[0][0] - cote / 2, y = f.pts[0][1] - cote / 2; l.push({ d: "M" + x + " " + y + "h" + cote + "v" + cote + "h" + (-cote) + "Z" }); } } return l; } /** * Le hall en noir et blanc. * * Le canevas fait le gros du travail : il sait remplir un contour et * l'épaissir d'un trait, ce qui donne l'écart au mur sans une ligne de * géométrie. On peint donc tout en mur, on creuse l'enveloppe, on y replante * les stands, et on relit les pixels. */ function grille(p, pmr){ const cle = p.id + (pmr ? "|pmr" : ""); const garde = GRILLES.get(cle); if (garde) return garde; const e = p.emprise; const w = Math.ceil((e.x1 - e.x0) / PAS_GRILLE) + 2; const h = Math.ceil((e.y1 - e.y0) / PAS_GRILLE) + 2; const cv = document.createElement("canvas"); cv.width = w; cv.height = h; const ctx = cv.getContext("2d", { willReadFrequently: true }); // une case pour un demi-mètre, décalée d'une case pour garder une marge ctx.setTransform(1 / PAS_GRILLE, 0, 0, 1 / PAS_GRILLE, 1 - e.x0 / PAS_GRILLE, 1 - e.y0 / PAS_GRILLE); ctx.lineJoin = ctx.lineCap = "round"; ctx.lineWidth = 2 * (pmr ? DEGAGEMENT_PMR : DEGAGEMENT); ctx.fillStyle = ctx.strokeStyle = "#000"; const barre = (d, trait) => { const t = new Path2D(d); if (!trait) ctx.fill(t); ctx.stroke(t); }; ctx.fillRect(e.x0 - 2, e.y0 - 2, e.x1 - e.x0 + 4, e.y1 - e.y0 + 4); /* On creuse ce qui est praticable. Si l'exploitant a dessiné la circulation, c'est elle qui fait foi, et rien d'autre du pavillon n'est ouvert. Sinon on retombe sur l'enveloppe des emplacements, qui vaut mieux que rien mais ignore tout ce que le fond de plan est seul à savoir. */ const circulation = formesRole(p, "circulation").map(o => new Path2D(o.d)); const ouvert = circulation.length ? circulation : [enveloppe(p)]; ctx.globalCompositeOperation = "destination-out"; ouvert.forEach(t => ctx.fill(t)); ctx.globalCompositeOperation = "source-over"; // le bord d'une circulation est un mur comme un autre : on s'en écarte ouvert.forEach(t => ctx.stroke(t)); for (const o of p.stands) barre(o.d); for (const o of p.zones) barre(o.d); formesRole(p, "obstacle").forEach(o => barre(o.d, o.trait)); if (pmr) obstaclesPmr(p).forEach(o => barre(o.d, o.trait)); const px = ctx.getImageData(0, 0, w, h).data; const mur = new Uint8Array(w * h); // le lissage du canevas laisse des bords à demi peints : au-delà de la // moitié, la case est du côté du mur for (let i = 0; i < mur.length; i++) mur[i] = px[i * 4 + 3] > 128 ? 1 : 0; const g = { x0: e.x0 - PAS_GRILLE, y0: e.y0 - PAS_GRILLE, w: w, h: h, mur: mur }; g.marge = distanceAuMur(g); g.nappe = nappePrincipale(g); GRILLES.set(cle, g); return g; } /** * À combien de cases chaque case est-elle du mur le plus proche ? * * C'est ce qui permet de tenir le milieu d'une allée plutôt que d'en raser un * bord. Deux balayages suffisent — un descendant, un remontant, chacun ne * regardant que les voisins déjà vus : la distance se propage de proche en * proche. On la plafonne bas, seuls les premiers mètres nous intéressent. */ function distanceAuMur(g){ const n = g.w * g.h, PLAFOND = 30; const d = new Uint8Array(n); const D = Math.SQRT2; const met = (i, v) => { d[i] = v > PLAFOND ? PLAFOND : Math.round(v); }; const lu = new Float32Array(n); for (let i = 0; i < n; i++) lu[i] = g.mur[i] ? 0 : 1e6; for (let y = 0; y < g.h; y++) for (let x = 0; x < g.w; x++){ const i = y * g.w + x; if (lu[i] === 0) continue; let m = lu[i]; if (x > 0) m = Math.min(m, lu[i - 1] + 1); if (y > 0) m = Math.min(m, lu[i - g.w] + 1); if (x > 0 && y > 0) m = Math.min(m, lu[i - g.w - 1] + D); if (x < g.w - 1 && y > 0) m = Math.min(m, lu[i - g.w + 1] + D); lu[i] = m; } for (let y = g.h - 1; y >= 0; y--) for (let x = g.w - 1; x >= 0; x--){ const i = y * g.w + x; if (lu[i] === 0) continue; let m = lu[i]; if (x < g.w - 1) m = Math.min(m, lu[i + 1] + 1); if (y < g.h - 1) m = Math.min(m, lu[i + g.w] + 1); if (x < g.w - 1 && y < g.h - 1) m = Math.min(m, lu[i + g.w + 1] + D); if (x > 0 && y < g.h - 1) m = Math.min(m, lu[i + g.w - 1] + D); lu[i] = m; met(i, m); } return d; } /** * La nappe où l'on marche vraiment. * * Le vide d'un hall n'est pas d'un seul tenant : quatre stands mitoyens * laissent entre eux des poches fermées de deux ou trois cases, et une cour * intérieure peut n'avoir aucune issue. S'accrocher à l'une d'elles rendait * une vingtaine d'emplacements du pavillon 7.2 injoignables, alors que leur * allée était à quatre mètres. On repère donc une fois pour toutes la plus * grande nappe — les allées du hall — et c'est à elle que les points * s'accrochent. */ function nappePrincipale(g){ const n = g.w * g.h; const marque = new Int32Array(n).fill(-1); const file = new Int32Array(n); const tailles = []; for (let d = 0; d < n; d++){ if (g.mur[d] || marque[d] >= 0) continue; const id = tailles.length; let fin = 0, tete = 0; file[fin++] = d; marque[d] = id; while (tete < fin){ const i = file[tete++]; const cx = i % g.w, cy = (i - cx) / g.w; // quatre voisins, comme le trajet : deux cases en diagonale ne // communiquent pas plus ici qu'on ne passe entre deux angles de stand for (let k = 0; k < 4; k++){ const nx = cx + VX[k], ny = cy + VY[k]; if (nx < 0 || ny < 0 || nx >= g.w || ny >= g.h) continue; const j = ny * g.w + nx; if (g.mur[j] || marque[j] >= 0) continue; marque[j] = id; file[fin++] = j; } } tailles.push(fin); } let gagnante = -1, mieux = 0; tailles.forEach((t, i) => { if (t > mieux){ mieux = t; gagnante = i; } }); const nappe = new Uint8Array(n); for (let i = 0; i < n; i++) if (marque[i] === gagnante) nappe[i] = 1; return nappe; } function caseDe(g, x, y){ const cx = Math.floor((x - g.x0) / PAS_GRILLE), cy = Math.floor((y - g.y0) / PAS_GRILLE); if (cx < 0 || cy < 0 || cx >= g.w || cy >= g.h) return -1; return cy * g.w + cx; } function centreCase(g, i){ const cx = i % g.w, cy = (i - cx) / g.w; return [g.x0 + (cx + .5) * PAS_GRILLE, g.y0 + (cy + .5) * PAS_GRILLE]; } /* Jusqu'où l'on accepte de chercher l'allée d'un point : douze mètres, la profondeur d'un très grand stand. Au-delà, on ne s'écarte plus — un point qu'aucune allée n'atteint doit rester injoignable, sinon le mode accessible tracerait des trajets vers des stands qu'il vient précisément d'exclure. */ const PORTEE_ACCROCHE = 24; /** * La case de la nappe principale la plus proche d'un point. * * Le centre d'un stand tombe dans le mur — c'est bien lui qu'on désigne, mais * c'est l'allée devant lui qu'on emprunte. On s'écarte donc en anneaux, murs * compris, jusqu'à toucher les allées : la façade la plus accessible est * atteinte la première, sans qu'on ait eu à la chercher. */ function accroche(g, xy){ let d = caseDe(g, xy[0], xy[1]); if (d < 0){ const cx = Math.min(g.w - 1, Math.max(0, Math.floor((xy[0] - g.x0) / PAS_GRILLE))); const cy = Math.min(g.h - 1, Math.max(0, Math.floor((xy[1] - g.y0) / PAS_GRILLE))); d = cy * g.w + cx; } if (g.nappe[d]) return d; const dx0 = d % g.w, dy0 = (d - dx0) / g.w; const vu = new Uint8Array(g.w * g.h); const file = [d]; vu[d] = 1; let repli = -1; for (let k = 0; k < file.length; k++){ const i = file[k], cx = i % g.w, cy = (i - cx) / g.w; // en huit voisins, le rang de l'anneau se lit sur les coordonnées if (Math.max(Math.abs(cx - dx0), Math.abs(cy - dy0)) > PORTEE_ACCROCHE) break; for (let dy = -1; dy <= 1; dy++) for (let dx = -1; dx <= 1; dx++){ const nx = cx + dx, ny = cy + dy; if (nx < 0 || ny < 0 || nx >= g.w || ny >= g.h) continue; const j = ny * g.w + nx; if (vu[j]) continue; vu[j] = 1; if (g.nappe[j]) return j; // une poche fermée ne mène nulle part : on la traverse sans s'y arrêter if (repli < 0 && !g.mur[j]) repli = j; file.push(j); } } return repli; } /* ------------------------------------------------------------ A* ------------------------------------------------------------ */ /* Un tas binaire sur deux tableaux parallèles. C'est le seul endroit où un A* écrit naïvement s'effondre : chercher le minimum d'une liste à chaque tour coûte plus que tout le reste du calcul réuni. */ function Tas(){ this.f = []; this.i = []; } Tas.prototype.pousse = function (f, i){ const F = this.f, I = this.i; let k = F.length; F.push(f); I.push(i); while (k > 0){ const p = (k - 1) >> 1; if (F[p] <= F[k]) break; const a = F[p]; F[p] = F[k]; F[k] = a; const b = I[p]; I[p] = I[k]; I[k] = b; k = p; } }; Tas.prototype.tire = function (){ const F = this.f, I = this.i; const tete = I[0], n = F.length - 1; F[0] = F[n]; I[0] = I[n]; F.pop(); I.pop(); let k = 0; for (;;){ const g = 2 * k + 1, d = g + 1; let m = k; if (g < F.length && F[g] < F[m]) m = g; if (d < F.length && F[d] < F[m]) m = d; if (m === k) break; const a = F[m]; F[m] = F[k]; F[k] = a; const b = I[m]; I[m] = I[k]; I[k] = b; k = m; } return tete; }; /* Les quatre directions, dans cet ordre : est, ouest, sud, nord. */ const VX = [1, -1, 0, 0]; const VY = [0, 0, 1, -1]; /** * Les tableaux de travail de la recherche, alloués une fois pour toutes. * * Un état n'est pas une case mais une case abordée dans une direction : il y * en a donc quatre fois plus, et les réallouer à chaque trajet coûterait plus * que la recherche. Un compteur de tour évite de les remettre à zéro : un état * dont le tampon n'est pas celui du tour n'a jamais été visité. */ let TRAVAIL = null; function travail(taille){ if (!TRAVAIL || TRAVAIL.cout.length < taille){ TRAVAIL = { cout: new Float32Array(taille), pere: new Int32Array(taille), etat: new Int32Array(taille), tour: 0 }; } return TRAVAIL; } /** * Le plus court chemin de case à case, ou null s'il n'en existe aucun. * * Quatre voisins, jamais huit : une diagonale de grille n'a pas d'équivalent * dans une allée, et c'est elle qui faisait traverser les allées en biais. * Reste que mille escaliers valent la même longueur — d'où le prix du virage, * qui tranche en faveur des longues lignes droites, et le prix du bord, qui * tient le trait au milieu du passage. L'état porte donc la direction d'où * l'on vient, sans quoi un virage ne se verrait pas. */ function cherche(g, depart, arrivee){ if (depart === arrivee) return [depart]; const m = travail(g.w * g.h * 4); const tour = ++m.tour; const ax = arrivee % g.w, ay = (arrivee - ax) / g.w; // Manhattan : sur quatre voisins et au pas d'une case, elle ne surestime // jamais le trajet — condition pour qu'A* rende bien le plus court const reste = (i) => { const x = i % g.w, y = (i - x) / g.w; return Math.abs(x - ax) + Math.abs(y - ay); }; const bord = (i) => { const l = g.marge[i]; return l >= PORTEE_CENTRE ? 0 : POIDS_CENTRE * (PORTEE_CENTRE - l) / PORTEE_CENTRE; }; const tas = new Tas(); /* Les quatre directions de départ coûtent zéro : le premier pas ne paie aucun virage, on n'arrivait de nulle part. */ for (let d = 0; d < 4; d++){ const s = depart * 4 + d; m.etat[s] = tour; m.cout[s] = 0; m.pere[s] = -1; tas.pousse(reste(depart), s); } let dernier = -1; while (tas.f.length){ const s = tas.tire(); if (m.etat[s] === -tour) continue; // déjà close const i = (s / 4) | 0, d = s & 3; if (i === arrivee){ dernier = s; break; } m.etat[s] = -tour; const cx = i % g.w, cy = (i - cx) / g.w; for (let k = 0; k < 4; k++){ const nx = cx + VX[k], ny = cy + VY[k]; if (nx < 0 || ny < 0 || nx >= g.w || ny >= g.h) continue; const j = ny * g.w + nx; if (g.mur[j]) continue; const s2 = j * 4 + k; if (m.etat[s2] === -tour) continue; const c = m.cout[s] + 1 + bord(j) + (k === d ?
