/* ============================================================ 13. Mesure d'utilisation L'organisateur paie le plan et ne sait pas s'il sert. Ce module compte les gestes — une visite, une recherche, une fiche ouverte et par quel chemin — et les pousse par paquets vers la fonction `mesure`. Le rapport se lit depuis la console, sur sa page dédiée. Chaque paquet dit aussi **par quelle porte** le plan a été atteint : un navigateur, un cadre posé dans la page d'un site tiers, une installation sur l'écran d'accueil, une coque d'application. Sans cela les quatre se mélangeaient dans un chiffre unique, et ce chiffre ne voulait rien dire — une page encadrée ouvre une visite à chaque page du site qui la porte, une application repart à froid vingt fois par jour, un cadre tiers se voit refuser le stockage et gonfle les visiteurs uniques. Séparées, les quatre portes se lisent ; mélangées, aucune. Trois choses qu'il ne fait pas, et c'est ce qui permet de le laisser tourner sans bandeau de consentement : il ne pose pas de cookie, il n'envoie ni adresse ni agent utilisateur — le serveur ne les enregistre pas davantage — et le jeton de visiteur est tiré au hasard par le navigateur, propre à cet événement. Il ne suit personne d'un salon à l'autre, encore moins ailleurs. La porte n'y change rien : c'est la façon dont la page est affichée, pas une propriété de qui la regarde, et elle ne prend que quatre valeurs. Il se tait complètement dans deux cas : la page à données figées, qui n'a aucune API à appeler, et la page d'administration, où ce qu'on mesurerait serait l'exploitant en train de préparer son salon. ============================================================ */ const MESURE_API = API ? API.replace(/[^/]*$/, "mesure") : ""; const MESURE_ACTIVE = !!(MESURE_API && SLUG && document.documentElement.dataset.role !== "admin"); /** Un jeton de quelques caractères, tiré du générateur du navigateur. */ function jetonMesure(){ const t = new Uint8Array(9); (crypto && crypto.getRandomValues ? crypto : { getRandomValues: a => { for (let i = 0; i < a.length; i++) a[i] = Math.floor(Math.random() * 256); } }).getRandomValues(t); return Array.from(t, o => o.toString(36).padStart(2, "0")).join(""); } /* Le stockage a-t-il accepté de retenir le jeton. Faux, le jeton ne vaut que pour cette ouverture, et le paquet le dit au serveur : le rapport compte alors ce visiteur comme les autres — il a bien ouvert le plan — mais sait qu'il le recompte peut-être, et l'annonce au lieu de gonfler une audience en silence. C'est le cas ordinaire d'un cadre posé sur un site tiers. */ let MESURE_RETENU = true; /** * Le jeton retenu, ou un jeton volatil si le stockage est refusé. * * En navigation privée, ou stockage plein, l'écriture lève. On ne renonce pas * à mesurer pour autant : le visiteur comptera pour un de plus, ce qui vaut * mieux que de ne pas le compter du tout. * * Le casier est nommé plutôt que passé : quand le navigateur refuse le * stockage de site — cookies bloqués — c'est la simple lecture de * `localStorage` qui lève, et l'évaluer à l'appel plaçait cette lecture hors * du `try`. L'exception remontait alors au corps de la page, dans le script * qui porte tout le plan : plus rien ne s'affichait, pour une mesure. */ function jetonRetenu(cle, casier){ try { const ou = window[casier]; const v = ou.getItem(cle); if (v) return v; const n = jetonMesure(); ou.setItem(cle, n); return n; } catch (e) { MESURE_RETENU = false; return jetonMesure(); } } /* Les quatre portes, dans le vocabulaire du serveur, qui écarte tout le reste. Elles n'ont pas la même façon d'être reconnues, d'où l'ordre ci-dessous. */ const SUPPORTS = ["web", "integre", "pwa", "appli"]; /** * Par quelle porte cette page a été atteinte. * * L'ordre des épreuves est celui de la certitude décroissante. * * Une coque d'application le **dit**, parce que rien dans la page ne permet de * le voir : une vue web plein écran qui charge la page hébergée est en tout * point un navigateur. C'est donc à l'hôte de l'annoncer, par `?support=appli` * ajouté à l'adresse qu'il ouvre — une déclaration, pas une preuve, et le * vocabulaire clos borne ce qu'elle peut raconter. Les coques qui servent la * page depuis l'appareil se reconnaissent en plus à leur protocole. * * Un cadre se voit : le document n'est pas au sommet de sa fenêtre. La * comparaison reste permise entre origines différentes, et un cadre bac à sable * qui la refuserait est encadré de toute façon. * * Une installation sur l'écran d'accueil se lit dans le mode d'affichage. * `navigator.standalone` est la forme d'iOS, qui la produit sans qu'aucun * manifeste existe — ces visites se comptaient donc déjà, sous « web ». * * Rien de tout cela ne dit quoi que ce soit du visiteur : c'est la façon dont * la page est affichée, et elle ne prend que quatre valeurs. */ function supportMesure(){ const dit = new URLSearchParams(location.search).get("support"); if (dit && SUPPORTS.includes(dit)) return dit; if (/^(capacitor|ionic|app|tauri):$/.test(location.protocol)) return "appli"; try { if (window.top !== window.self) return "integre"; } catch (e) { return "integre"; } if (navigator.standalone === true) return "pwa"; try { if (["standalone", "fullscreen", "minimal-ui", "window-controls-overlay"] .some(m => matchMedia("(display-mode: " + m + ")").matches)) return "pwa"; } catch (e) {} return "web"; } /* Relevé une fois, au chargement : la porte est la façon dont la page a été ouverte, et une page ouverte ne change pas de porte. Une installation faite en cours de route ne vaudra donc que pour le lancement suivant — c'est aussi ce qu'on veut compter. */ const MESURE_SUPPORT = MESURE_ACTIVE ? supportMesure() : ""; /* Le jeton de visiteur est rangé sous le nom de l'événement : deux salons ouverts sur le même téléphone n'ont pas le même, et aucun ne vaut comme identifiant hors d'ici. Ce qui distinguait deux venues du même navigateur ne se transmet plus : le serveur ne le lisait pas, et une visite se compte déjà par le geste qui porte ce nom. */ const MESURE_VISITEUR = MESURE_ACTIVE ? jetonRetenu("plan-visiteur:" + SLUG, "localStorage") : ""; /* Un geste ne vaut pas un aller-retour réseau : on accumule, et on envoie quand le paquet est plein, quand la main s'arrête, ou quand la page part. Trente secondes et non quatre : à quatre, chaque fiche ouverte au fil d'une visite partait dans son propre paquet, et un visiteur produisait une quinzaine de requêtes — de loin le premier poste d'appels du système, devant le plan lui-même. Rien ne se perd pour autant, le départ de la page vidant ce qui reste. */ const MESURE_PAQUET = 20; const MESURE_DELAI = 30000; let _gestes = [], _envoiDiffere = null; function envoieMesures(dernier){ clearTimeout(_envoiDiffere); _envoiDiffere = null; if (!_gestes.length) return; /* Le support accompagne le paquet, non chacun de ses gestes : c'est une propriété de l'ouverture de la page, pas du geste qu'on y fait, et le répéter trente fois l'exposerait à se contredire. */ const charge = JSON.stringify({ slug: SLUG, visiteur: MESURE_VISITEUR, support: MESURE_SUPPORT, retenu: MESURE_RETENU, gestes: _gestes.splice(0, _gestes.length), }); /* Au départ de la page, `fetch` est coupé net par le navigateur : le paquet se perdrait, et avec lui les derniers gestes — souvent les plus parlants. `sendBeacon` est fait pour cela, il survit à la fermeture de l'onglet. */ try { if (dernier && navigator.sendBeacon && navigator.sendBeacon(MESURE_API, charge)) return; } catch (e) {} fetch(MESURE_API, { method: "POST", headers: { "Content-Type": "application/json" }, body: charge, keepalive: true, // la mesure ne doit jamais gêner la visite : une panne se tait }).catch(() => {}); } /** * Retenir un geste, et ce qu'il désignait s'il désignait quelque chose. * * mesure("fiche_stand", "plan", o.id) une fiche d'exposant, ouverte du plan * mesure("recherche") une recherche menée à son terme * mesure("itineraire", "", o.id, "fiche_stand") la route jusqu'à ce stand * * `objet` dit ce que la cible désigne, et ne se donne que là où le genre ne le * dit pas déjà : une fiche ouverte désigne l'objet qui porte son nom, un * itinéraire ou un ajout au programme peut viser un stand comme une * conférence. Le serveur le déduit du genre quand il manque. * * Le vocabulaire est celui des compteurs ; le serveur écarte ce qu'il ne * connaît pas plutôt que de l'enregistrer sous un nom approximatif, et une * cible que l'événement ne porte pas est écartée de même. */ function mesure(genre, canal, cible, objet){ if (!MESURE_ACTIVE) return; const g = { genre: genre }; if (canal) g.canal = canal; if (cible) g.cible = cible; if (cible && objet) g.objet = objet; _gestes.push(g); if (_gestes.length >= MESURE_PAQUET) return envoieMesures(); clearTimeout(_envoiDiffere); _envoiDiffere = setTimeout(() => envoieMesures(), MESURE_DELAI); } if (MESURE_ACTIVE){ /* Une visite par session d'onglet. Rouvrir le plan après l'avoir fermé en fait une seconde ; naviguer dedans pendant deux heures, une seule. Ce que « une session d'onglet » dure ne dépend pas de nous, et c'est précisément pourquoi le rapport sépare les portes : un lancement depuis l'écran d'accueil en ouvre une neuve à chaque fois, et une page de site qui porte le cadre en ouvre une par page vue. Les visites se comparent dans une porte, jamais d'une porte à l'autre. */ const CLE_VUE = "plan-visite:" + SLUG; let dejaVue = false; try { dejaVue = !!sessionStorage.getItem(CLE_VUE); } catch (e) {} if (!dejaVue){ try { sessionStorage.setItem(CLE_VUE, "1"); } catch (e) {} mesure("visite"); } /* `pagehide` est le seul événement sur lequel on puisse compter partout : sur mobile, une page mise en arrière-plan n'est jamais « déchargée », elle est gelée puis jetée sans prévenir. */ addEventListener("pagehide", () => envoieMesures(true)); addEventListener("visibilitychange", () => { if (document.visibilityState === "hidden") envoieMesures(true); }); }
